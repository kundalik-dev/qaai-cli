QAAI CLI Cheat Sheet

Quick: qaai go <shortcut> qaai search <query> qaai launch vscode npm install -g qaai-cli URL shortcuts →
Open Websites
Open a shortcut (e.g. github):
qaai go github
Open any URL directly:
qaai go https://example.com
Search
Search Google for a single-word query:
qaai search typescript
Search Google for a multi-word query:
qaai search react hooks tutorial
Open Apps
Open VSCode in the current directory:
qaai launch vscode
Open VSCode at a specific folder path:
qaai launch vscode D:\my-project
Installation
Install qaai globally from npm:
npm install -g qaai-cli
Link locally for development and testing:
npm link
